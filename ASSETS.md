# Ikony i zasoby

Folder `assets/fallback_items` zawiera oryginalne, zastępcze ikony przygotowane
dla Restriction Generatora. Nie są to oficjalne tekstury Minecrafta ani tekstury
pochodzące z modów.

Program może podczas działania odczytać prawdziwe ikony przedmiotów z lokalnych
plików użytkownika:

- klienta Minecraft 1.21.1,
- wybranych plików JAR modów.

Te pliki służą wyłącznie do lokalnego podglądu. Program nie kopiuje ich do
projektu, eksportowanego datapacka ani dołączonej dystrybucji.

Minecraft jest znakiem towarowym Mojang Synergies AB. Ten projekt nie jest
oficjalnym produktem Mojang ani Microsoftu i nie jest przez nich zatwierdzony.
